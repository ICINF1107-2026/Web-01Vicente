Qué deben entregar
1. Sitio del portafolio (repositorio GitHub personal):
• Un archivo HTML con estructura semántica (header, nav, main, section, footer) que incluya, como
mínimo, 3 secciones: presentación personal / sobre mí, trabajos o prácticas del semestre, y contacto.
• CSS externo (archivo separado) con diseño responsivo en 3 puntos de quiebre (móvil, tablet,
escritorio).
• Jerarquía visual clara (encabezados coherentes, contraste, espaciado, foco visual).
• Accesibilidad básica: contraste suficiente, textos alternativos (alt), etiquetas en formularios (label), foco
navegable con teclado, estructura de encabezados jerárquica.
• Estructura de carpetas ordenada (ej.: index.html, css/, img/) y README.md con: descripción,
tecnologías, capturas, cómo abrirlo y las decisiones de diseño tomadas.
2. Presentación oral individual (5 min) + 2–3 preguntas:
• 1 min: quién es el usuario/audiencia del portafolio (ej.: reclutador, cliente, docente) y qué necesita ver.
• 2–3 min: recorrido del portafolio justificando decisiones de diseño (estructura, jerarquía, responsividad,
accesibilidad).
